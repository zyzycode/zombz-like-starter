# Пепельный путь — roguelike alpha

Локальная одиночная top-down игра на React, Phaser и TypeScript.

## Запуск

```bash
npm install
npm run dev
```

Открыть адрес Vite (обычно http://localhost:5173). Для production: `npm run build`, затем `npm run preview`.

## Игровой цикл

Шесть уровней в трёх биомах: заросшая роща, пепельные руины, мёрзлое святилище. На каждом уровне две волны. После зачистки — выбор одного из трёх случайных предметов и восстановление 25% максимального здоровья перед следующим уровнем. В конце пути — босс с круговым ударом и залпом снарядов.

- Ближний бой, огненный болт, магическое кольцо и рывок с неуязвимостью.
- Пять архетипов врагов: обычный страж, быстрый охотник, тяжёлый страж, стрелок и босс.
- Опыт за врагов и зачистку; три ветки навыков по два узла с несколькими рангами.
- Инвентарь, оружие, доспех и талисман; обычные, редкие и эпические награды. Первый предмет пустого слота надевается автоматически, замену можно выбрать вручную.
- Экипировка и навыки доступны на паузе и экране награды.
- Мета-валюта: 4 осколка за зачищенный уровень и ещё 12 за победу. Она начисляется при смерти, победе или выходе через меню. Постоянные улучшения действуют со следующего забега.
- После смерти временный билд теряется. Постоянный профиль хранится в localStorage (`zombs-alpha-profile-v1`). Текущий незавершённый забег при перезагрузке не сохраняется.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | WASD |
| Направление атаки | Курсор |
| Ближний бой | Удерживать ЛКМ или Space |
| Огненный болт (20 маны) | Q |
| Магическое кольцо (40 маны) | R |
| Рывок | Shift |
| Пауза / развитие персонажа | Esc |

При потере фокуса бой автоматически ставится на паузу. Цифры баланса предварительные.

## Архитектура

- `src/game/core`: игровая симуляция без Phaser, React и браузерного хранилища; бой, снаряды, билд, навыки, метапрогрессия.
- `src/game/session/RunController.ts`: жизнь забега, переходы, награды и завершение. Один `RunSession` на все уровни.
- `src/game/core/world/GameWorld.ts`: симуляция одного уровня. Campaign сообщает active/cleared/dead, контроллер завершает весь забег. Старый extraction-режим сохранён для исходной карты.
- `src/game/content/campaign`: маршрут, состав волн и связанные арены с разным покрытием и препятствиями.
- `src/game/session/LocalMetaProfileRepository.ts`: граница localStorage, проверка сохранений и обработка ошибок хранения.
- `src/game/presentation/phaser`: ввод, камера, загрузка, графика и боевые эффекты.
- `src/ui/hud`: React-интерфейс; команды проходят через `RunActions` к контроллеру.

## Состояние альфы

Игровой маршрут и основные системы реализованы. Используются исходные спрайты: архетипы различаются цветом и размером; препятствия и магические эффекты — простые фигуры. Уникального арта для каждого биома/врага, музыки, звука, сохранения незавершённого забега и сетевой игры пока нет. Арены фиксированные, случайны награды и разброс точек появления врагов.

## Проверки и разработка

`npm test` — ключевые сценарии крупных изменений (Node.js 22+). `npm run build` — TypeScript и production bundle. Не требуется запускать их после каждой мелкой правки.

Проверяется полный маршрут из шести уровней, перенос состояния, однократные награды, смерть/перезапуск, билд и метапрофиль, магия/рывок/снаряды и lifecycle загрузки. Проверки логики не заменяют ручную оценку удобства боя и баланса.
