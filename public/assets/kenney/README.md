# Kenney environment art

These CC0 assets are used by the campaign arenas:

- **Tiny Town**, Kenney: https://kenney.nl/assets/tiny-town
  - Author's OpenGameArt publication: https://opengameart.org/content/tiny-town
  - Downloaded archive: https://opengameart.org/sites/default/files/kenney_tiny-town.zip
  - Included original license: `LICENSE-tiny-town.txt`.
- **Tiny Dungeon**, Kenney: https://kenney.nl/assets/tiny-dungeon
  - Author's OpenGameArt publication: https://opengameart.org/content/tiny-dungeon
  - Downloaded archive: https://opengameart.org/sites/default/files/kenney_tinydungeon.zip
  - Included original license: `LICENSE-tiny-dungeon.txt`.

License: Creative Commons Zero (CC0 1.0), https://creativecommons.org/publicdomain/zero/1.0/.
Kenney permits personal and commercial use; attribution is appreciated but not required.

`tiny-town-32.png` and `tiny-dungeon-32.png` are the original packed tilemaps,
scaled from 16 px to 32 px per tile with nearest-neighbor sampling. Tile order
is unchanged (12 columns). `tiny-town-frost-32.png` and
`tiny-dungeon-frost-32.png` are local color variants of those same sheets:
greens and warm earth colors were mapped to snow/ice colors before scaling.
These are adapted existing artwork, not newly drawn art.

Kenney character tiles are static and are not used for movement/attack animations.
The hero uses the separately licensed Legend pack; enemies retain their previous sheets.
